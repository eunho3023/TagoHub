# 손으로 옮겨 둔 첫차·막차

자동으로 받을 수 없는 지자체 시간표를 공개 화면에서 읽어 옮겨 둔 파일입니다. `build_data.fill_city_times`가 TAGO에 첫차·막차가 없는 노선만 노선 번호로 맞춰 채웁니다. 한 노선 번호의 여러 갈래에는 모두 같은 노선 전체 첫차·막차가 들어갑니다.

| 파일 | 출처 | 읽은 날 |
|---|---|---|
| `gyeongsan.csv` | 경산시 교통정보센터 버스운행 시간표 (its.gbgs.go.kr/bis.web/timetable.do), 평일 첫차·막차 | 2026-11-25 |
| `changnyeong.csv` | 공공데이터포털 15005337 경상남도 창녕군_버스운행정보_농어촌버스 (기준 2026-05-08). 노선명 괄호 앞 번호, 기점 시각 중 가장 이른·늦은 것 | 2026-11-25 |
| `yeongyang.csv` | 공공데이터포털 15054389 경상북도 영양군_버스 배차시간표 (기준 2025-11-11). 노선 번호마다 한 운행 → 첫 정류장 시각 중 가장 이른·늦은 것 | 2026-11-25 |

노선 개편 소식이 있으면 같은 화면에서 다시 읽어 고칩니다. `하양1`은 화면 표가 다른 줄과 섞여 있어 넣지 않았습니다.

공공데이터포털 파일은 갱신 주기가 연간이라, 새 파일이 올라오면(포털 '차기 등록 예정일') 다시 받아 같은 방식으로 옮깁니다. 영양 160·161·162·175 는 파일에 없어 비어 있습니다.
