# 노선 API가 없는 지역의 노선 파일

TAGO·지자체 API에 노선이 없는 지역의 노선, 정류장 순서, 출발 시각을 공개 자료에서 옮겨 둔 파일입니다. `build_data.write_static_routes`가 DB에 넣습니다. 출발 시각은 `fetch_city_times.py`가 배포할 때 웹 시간표 조각(`data/times/<지역>.json`)으로 만듭니다.

## 파일 형식
| 파일 | 칸 |
|---|---|
| `routes.csv` | 노선ID, 노선번호, 기점, 종점 |
| `stops.csv` | 노선ID, 정류소순번, 정류소명, 상하행구분, (위도, 경도) |
| `deps.csv` | 노선ID, 방향코드(1 기점·2 종점 출발), 출발시간, 적용운행일 |

강릉 파일은 공공데이터포털 원본 칸을 그대로 둡니다.

정류장 좌표는 원본 파일에 없습니다. 그래서 이름이 같은 우리 정류장 중 앞 정류장에 가장 가까운 것으로 잇습니다.

우리 정류장에 없는 이름은 브이월드(국토교통부) 지명·장소 검색으로 찾은 좌표를 `위도`·`경도` 칸에 넣어 두었습니다(2026-11-25). 앞뒤로 위치를 아는 정류장 사이 길목 안에 있는 결과만 썼습니다. 결과: 강릉 1,375곳 중 928곳, 완주 380곳 중 157곳. 2026-11-26 완주는 이름을 나누고(하용·마안 → 하용) 앞의 '원'·뒤의 '삼거리'를 빼서 다시 찾아 92곳을 더 채웠습니다. 이때 브이월드 장소 중 '○○마을(버스정류장)'을 먼저 쓰고, 면·군 중심은 버렸습니다. 좌표가 없는 정류장은 이름만 남습니다.

속초 파일은 정류장마다 좌표가 있습니다. 그 자리 300m 안의 같은 이름 정류장에만 잇고, 없으면 새 정류장으로 만듭니다. 이름만 다른 교통안전공단 정류장이 30m 안에 겹치면 데이터 만들기가 공단 정류장을 지웁니다(`drop_tsb_twin_stops`).

## 지역별 출처
| 폴더 | 노선 id | 출처 | 읽은 날 |
|---|---|---|---|
| `gangneung/` | GNB | 공공데이터포털 15178618 노선목록 · 15178624 노선별 정류소정보 · 15178626 배차정보 (강원특별자치도 강릉시, 기준 2026-11-13) | 2026-11-25 |
| `wanju/` | WNB | 완주군시설관리공단 공영마을버스 고산북부권 시간표(www.wjss.or.kr/index.do?contentsSid=262)와 노선도 안내 글(contentsSid=263) | 2026-11-25 |
| `sokcho/` | SKB | 속초시 버스정보시스템(bis.sokcho.go.kr) 노선별 정류장(순서·좌표)과 배차시간표(평일·토·일, 기점·종점 출발). 속초 시내·마을버스 48개, 고성 간성·대진과 양양까지 가는 노선 포함 | 2026-11-26 |

완주 자료에 대해:
- 구간(고산-운주 등)마다 노선 하나입니다.
- 정류장 순서는 노선도 글의 "주요 거점별 운행 노선"을 이어 만들었습니다(두 끝이 같은 거점 노선에 있으면 그 노선 그대로).
- 시간표에 요일 구분이 없어 매일 운행으로 넣었습니다. 코스별 경유지(백석·대둔산 등)는 반영하지 않았습니다.
- 출처는 완주군시설관리공단입니다. 공공누리 제4유형(출처표시, 상업적 이용금지, 변경금지) 조건으로 공개된 자료입니다.

속초 자료에 대해:
- 노선 이름의 갈래(1(간성C) 등)마다 노선 하나입니다. 같은 번호를 두 운수사가 다니면(7번 등) 따로 있습니다.
- 방학 시간표는 넣지 않았습니다.
- 원자료를 CSV 로 옮긴 도구는 저장소에 없습니다. 다시 받으려면 누리집 노선 지도(`/search/route/map?routeId=`)와 배차시간표(`/search/route/timeTable`) 응답을 같은 칸으로 옮기면 됩니다.
