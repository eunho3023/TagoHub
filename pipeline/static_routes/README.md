# 노선 API가 없는 지역의 노선 파일

TAGO·지자체 API에 노선이 없는 지역의 노선, 정류장 순서, 출발 시각을 공개 자료에서 옮겨 둔 파일입니다. `build_data.write_static_routes`가 DB에 넣습니다. 출발 시각은 `fetch_city_times.py`가 배포할 때 웹 시간표 조각(`data/times/<지역>.json`)으로 만듭니다.

## 파일 형식
| 파일 | 칸 |
|---|---|
| `routes.csv` | 노선ID, 노선번호, 기점, 종점 |
| `stops.csv` | 노선ID, 정류소순번, 정류소명, 상하행구분 |
| `deps.csv` | 노선ID, 방향코드(1 기점·2 종점 출발), 출발시간, 적용운행일 |

강릉 파일은 공공데이터포털 원본 칸을 그대로 둡니다.

정류장 좌표는 파일에 없습니다. 그래서 이름이 같은 우리 정류장 중 앞 정류장에 가장 가까운 것으로 잇습니다. 못 찾은 정류장은 이름만 남습니다.

## 지역별 출처
| 폴더 | 노선 id | 출처 | 읽은 날 |
|---|---|---|---|
| `gangneung/` | GNB | 공공데이터포털 15178618 노선목록 · 15178624 노선별 정류소정보 · 15178626 배차정보 (강원특별자치도 강릉시, 기준 2026-11-13) | 2026-11-25 |
| `wanju/` | WNB | 완주군시설관리공단 공영마을버스 고산북부권 시간표(www.wjss.or.kr/index.do?contentsSid=262)와 노선도 안내 글(contentsSid=263) | 2026-11-25 |

완주 자료에 대해:
- 구간(고산-운주 등)마다 노선 하나입니다.
- 정류장 순서는 노선도 글의 "주요 거점별 운행 노선"을 이어 만들었습니다(두 끝이 같은 거점 노선에 있으면 그 노선 그대로).
- 시간표에 요일 구분이 없어 매일 운행으로 넣었습니다. 코스별 경유지(백석·대둔산 등)는 반영하지 않았습니다.
- 출처는 완주군시설관리공단입니다. 공공누리 제4유형(출처표시, 상업적 이용금지, 변경금지) 조건으로 공개된 자료입니다.
