# 외부 API·데이터 약관 확인 표 (플레이스토어 배포 전)

이 앱이 쓰는 외부 API와 데이터를 코드·파이프라인에서 뽑아 정리했습니다.
**약관 내용은 아직 아무것도 읽거나 판단하지 않았습니다.** "확인 필요"는 직접 읽고 아래 빈칸에 적어 넣으라는 뜻입니다.
(2026-10-21 기준. "오늘 호출"은 이 PC에서 실제로 호출해 본 결과입니다.)

## 모든 API에 공통으로 확인할 질문

| # | 질문 | 왜 중요한가 |
|---|------|------------|
| 1 | **이용허락범위**(공공누리 유형 등)가 무엇인가 — 상업적 이용·변경 가능 여부 | 광고·유료 기능이 없어도 "배포"는 상업적 이용으로 볼 수 있는지 확인 |
| 2 | **앱에 넣어 재배포**해도 되는가 (앱에 번들한 파일·내 서버에 저장해 다시 제공 포함) | 저장본(릴리스에 올린 `ov_*`), 번들 데이터(`assets`), CCTV 중계가 해당 |
| 3 | **출처 표기** 문구와 위치 | 지금은 일부만 표기(`국토교통부 제공`, `한국도로공사 제공`, `UTIC 제공`) |
| 4 | **호출 한도**와 개발계정 → 운영계정 전환 조건 | 사용자가 늘면 키 하나의 한도를 모두가 같이 씀 |
| 5 | **키를 앱에 넣어도 되는가** (APK에서 읽힘) | 키 공유·노출 금지 조항이 있는지 |
| 6 | **캐시·저장 기간** 제한 | 폰 저장(7일 등)과 서버 저장이 해당 |

## 오늘 확인한 사실 (키 점검 중 발견)

- `local.properties`는 `=` 같은 글자를 `\=`로 저장하는 형식입니다. 이 파일을 그냥 읽으면 키가 틀려 보입니다(앱은 올바르게 읽습니다).
- 부산·광주 도착 API는 실제로 동작하고, 응답 필드가 만든 파서와 맞습니다(광주는 오류 확인 위치를 고쳤습니다).
- 울산은 **별도 활용신청이 필요**하고, 여수는 응답 자체가 오류(`04`)입니다. 두 곳은 지금 앱에서 도착 정보가 나오지 않습니다.
