## 1. 앱이 다루는 정보

앱은 **회원가입 없이 쓸 수 있습니다.** 앱을 처음 열면 Firebase 익명 로그인(이름·이메일 없는 무작위 ID)이 자동으로 만들어지고, 원하면 **이메일(비밀번호 또는 이메일 링크)·전화번호·구글 계정** 중 하나로 가입하거나 연결할 수 있습니다. 개발자가 쓰는 서버는 구글 Firebase(인증·Firestore)뿐이며, 아래 표의 "클라우드 저장" 항목만 저장합니다.

| 정보 | 왜 쓰는가 | 어디에 있는가 |
|---|---|---|
| **위치(GPS)** | 내 위치 표시, 주변 정류장, 길찾기 출발지, 경로 안내(회전·속도·단속카메라 알림), 하차 알림 | 기기 안에서만 처리. 길찾기를 할 때 출발지·목적지 좌표가 아래 3항의 지도·길찾기 제공처로 전달됨 |
| **검색어**(장소·정류장·노선) | 장소 검색 | 카카오 장소 검색에 전달됨 |
| **출근 알림**(켠 경우) | 정한 시각 전에 저장한 집→회사 대중교통 소요시간을 확인해 나갈 때를 알림 | 앱을 열지 않아도 알림 시각 무렵 백그라운드에서 **저장한 집·회사 좌표**가 카카오 길찾기에 전달됨 (이때 기기의 현재 위치는 쓰지 않음) |
| **즐겨찾기, 집·회사 장소, 안내 설정(안내받을 항목), 화면 모드, 야간 주행 모드, 차량 아이콘, 지도 종류** | 편의 기능, 앱을 지우거나 폰을 바꿔도 이어서 쓰기 | 기기에 저장하고 **클라우드 저장**: Firebase Firestore 의 `users/{내 ID}` 문서에 올림(익명 ID 또는 가입·연결한 계정 ID에 묶임). 집·회사는 **좌표와 이름**이 올라감. 안드로이드 자동 백업이 켜져 있으면 구글 계정 백업에도 포함될 수 있음 |
| **검색 기록(검색어)·경로 기록(출발·도착 이름과 좌표, 안내 시작 여부, 시각)** | 최근 검색·최근 경로를 다시 쓰기 | 기기에 저장하고 위와 같이 **클라우드 저장**. 앱의 기록 관리에서 하나씩·모두 지우거나, 기록 저장 스위치를 꺼서 새로 저장하지 않게 할 수 있음 |
| **이메일 가입·로그인**(선택) | 위 설정을 계정에 이어 두기 | **이메일 주소**와 비밀번호가 Firebase 인증에 저장됨(비밀번호는 구글이 암호화해 보관하며 개발자는 볼 수 없음). 설정 화면에 이메일이 표시됨. **이메일 링크**로 로그인하면 링크가 든 메일이 이 주소로 발송되고, 같은 폰에서 로그인을 마치려고 요청한 이메일 주소를 기기에 잠시 저장했다가 로그인이 끝나면 지움 |
| **전화번호 로그인**(선택) | 위 설정을 계정에 이어 두기 | **전화번호**가 Firebase 인증에 저장되고, 인증번호 문자(SMS)가 발송됨. 문자 요금이 부과될 수 있음. 구글은 스팸·악용을 막으려고 인증용으로 입력한 전화번호를 전송·저장함(구글 Firebase 안내). 전화번호만으로는 보안이 약해서 이메일·구글 계정도 함께 쓰기를 권장함 |
| **구글 계정 연결**(선택) | 위 설정을 계정에 이어 두기 | 연결하면 구글 계정의 **이메일 주소**가 Firebase 인증에 저장되고, 설정 화면에 표시됨 |
| **앱 제보**(보내기를 누른 경우만) | 오류·요청 접수 | 제보 **내용·종류, 앱 버전, 기기 제조사·모델, 안드로이드 버전, 내 ID**가 Firestore `reports` 에 저장됨. 개발자만 읽을 수 있음. 내용에 개인정보를 쓰지 마세요 |
| **오류 정보**(앱이 비정상 종료된 경우) | 원인 확인 | 기기 안에만 저장됨. 설정의 "최근 오류"에서 사용자가 직접 공유할 때만 밖으로 나감 |

광고 식별자, 연락처, 사진, 마이크 등은 사용하지 않습니다.

## 2. 사용하는 권한

- **위치**(정확한 위치·대략적인 위치): 위 목적. 앱을 사용하는 동안에만 쓰며, **백그라운드 위치 권한은 요청하지 않습니다.** 경로 안내·하차 알림은 앱 화면에서 시작하면 "위치 사용 중" 알림과 함께 동작하고, 알림의 버튼이나 앱에서 끌 수 있습니다.
- **알림**: 안내·하차 알림을 알림창에 표시
- **진동**: 하차 알림
- **알람 예약·부팅 완료 수신**: 막차 알림과 출근 알림을 정한 시각에 띄우고, 재부팅 뒤에도 유지
- **포그라운드 서비스(위치)·화면 꺼짐 방지**: 화면을 꺼도 경로 안내·하차 알림이 이어지도록
- **인터넷**: 지도·교통 정보를 받기 위해

## 3. 제3자에게 전달되는 정보

앱은 아래 제공처의 서비스를 호출하며, 호출할 때 **요청에 필요한 정보와 기기의 IP 주소**가 해당 제공처에 전달됩니다. 각 제공처의 처리 방침은 제공처 약관을 따릅니다.

- 카카오(지도, 장소 검색, 길찾기): 출발지·목적지·검색어 좌표/문구
- 공공데이터(국토교통부 TAGO·ITS, 한국도로공사, UTIC, 기상청, 한국철도공사, 서울·경기·부산·광주·울산·제주 등 지자체, 한국공항공사·인천국제공항공사 등): 정류장·노선 번호 등 조회 값. 사용자 식별 정보는 보내지 않음
- 구글 Firebase(인증·Firestore): 익명 ID, (가입·연결한 경우) 이메일·전화번호·구글 계정 이메일, 위 "클라우드 저장"·"앱 제보" 항목. 구글의 처리 방침을 따름
- 서울 교통빅데이터 플랫폼(T Data): 실시간 교차로 신호를 조회할 때 교차로 번호와 앱의 인증키가 전달됨. 사용자 식별 정보는 보내지 않음
- 데이터 저장소(GitHub Releases): 정류장·노선·도로 정보 파일을 내려받을 때 IP 주소가 전달됨
- [CCTV 중계 서버를 쓰는 경우: 영상 요청 시 IP 주소]

## 4. 보관과 삭제

기기에 저장된 즐겨찾기·집/회사·검색·경로 기록·캐시는 앱 설정 → 저장공간 → 데이터 삭제 또는 앱 삭제로 지울 수 있고, 검색·경로 기록은 앱의 기록 관리에서도 지울 수 있습니다. 클라우드에 올라간 설정·기록과 로그인 계정(이메일·전화번호 포함)은 앱 설정 → 계정 → **"내 데이터 삭제"** 로 바로 지울 수 있습니다(이 기기의 즐겨찾기·집/회사·안내 설정도 함께 비워짐). 앱 제보는 앱에서 읽거나 지울 수 없게 막아 두었으므로 [이메일] 로 삭제를 요청해 주세요(요청 시 제보 내용이나 날짜로 확인함). **[ ] Play 가 요구하는 "웹 삭제 안내 주소"는 이 문서를 공개한 페이지에 위 내용을 적어 그 주소를 쓰면 됩니다.**
